# AC 枭雄 — 核心机制

## 绳镖（Rope Launcher）— 本作标志性装备

由贝尔提供，AC 版蝙蝠侠钩爪。**不可摆动**，只有两种模式：

- **垂直上升**：瞄准高处边缘 → LB/L1 发射 → 秒到屋顶。取代慢速攀爬，任何 ledge 有图标提示
- **水平滑索**：两栋楼之间拉钢索 → 走平衡木或滑行过街。可在索上悬停→空中刺杀下方敌人
- **逃脱神器**：被发现时秒上屋顶、断视线、重新潜入
- **注意**：大本钟等任务有海拔要求（>30m），需要索上移动

## 双主角切换

- 开放世界自由切换（M 键），序列任务有时锁定角色
- **雅各布**：近战专精，更多终结技、更高伤害；专属指虎
- **伊薇**：潜行专精，更快隐匿、更远暗杀范围；高级鹰眼（升级后穿墙看敌人）；专属手杖剑
- 双主角有自己的技能树 + 专属任务

## 帮派系统（The Rooks / 黑鸦帮）

- **基地**：火车（移动总部的火车厢！），内有武器库、帮派升级面板、安全收入
- 伦敦 **7 个区**，初始被红帮 Blighters 控制
- 穿上绿色 = 黑鸦帮，红色 = 暴徒帮
- **帮派升级**：投钱让 Rooks 更强、更多出现在街头的帮派成员、马车随从、敌人见到你会犹豫

### 解放一区的流程
1. 刺杀该区圣殿骑士头目
2. 完成支线：猎杀圣殿骑士 / 解救童工 / 绑架关键罪犯
3. 帮派大战（群架 + boss）
4. 区变绿 → 快速旅行解锁 → 收入增加

## 马车系统

- **劫持**：任何马车都能跳上去抢（像 GTA 偷车）
- **马车战斗**：在车顶上打架、跳到敌方马车顶上
- **追逐战**：随机生成护送/劫持任务
- **绑架目标**：装进马车 → 立刻被识别 → 触发马车追逐
- **赛车**：街头竞速支线
- 开发者特意把街道做宽了，让驾驶体验不折磨

## 战斗系统

- 连击制战斗（类 AC 老式，非起源的 hitbox 制）
- 反击击杀 + 终结技（肾上腺素条满时释放）
- 双暗杀（解锁后可同时杀两个敌人）
- 远程：飞刀 / 六发左轮手枪 / 霍尔ucination 飞镖 / 伏特炸弹
- 环境击杀：墙、桌子、马车轮……
- 火车顶战斗、船只战斗

## 装备清单

- 双袖剑（雅各布一个带绳镖接口）
- 指虎（雅各布专属）/ 手杖剑（伊薇专属）
- 库克利弯刀
- 六发左轮手枪
- 飞刀
- 霍尔ucination 飞镖
- 伏特炸弹（电击范围攻击）
- 烟雾弹

## HUD 布局

- 左上：当前任务目标（白色文字）
- 顶部中：圆形罗盘小地图，金色菱形=主目标
- 右下：武器轮盘
- 底部：肾上腺素条（黄色分段）
- 左下：血条（红色）
- 潜行：白→黄→红（敌人警觉度）
- 鹰眼脉冲：金色高亮可交互目标/敌人/宝箱
- 马车：画面变宽，右下加速/刹车提示
- 帮派大战：屏幕上帮派势力条（红 vs 绿）

## 移动总结

屋顶跑酷（绳镖加速）> 滑索过街 > 马车驾驶 > 泰晤士河蒸汽船 > 火车快速旅行
