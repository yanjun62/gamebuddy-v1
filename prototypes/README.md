# GameBuddy 悬浮框视觉原型

## 范围

本目录保存独立界面概念稿，只验证悬浮聊天窗的视觉和交互方向。

- `qq_lite_overlay.py`：第一版 QQ-lite 白色气泡稿，已因办公软件感过强被否决。
- `pixel_neon_overlay.py`：第二版像素霓虹赛博朋克稿。
- `mucha_overlay.py`：第三版穆夏式新艺术海报稿，使用象牙纸、旧金、藤蔓与徽章语言。
- `mucha_illustrated_overlay.py`：第四版精绘新艺术稿，叠加真实石版画资产与最近三条消息交互层。

第四版依赖的项目资产位于 `assets/mucha-frame-v1.png`。该图由内置图像生成工具制作，原始提示要求：1890 年代新艺术彩色石版画、人物侧像与花卉藤蔓、旧金和象牙纸色盘、中央及底部保留低细节交互留白、不得生成文字或水印。

`font_specimen.py` 使用项目内随附的 OFL 开源字体生成独立字体样张，不修改交互窗口。字体及各自授权文件位于 `assets/fonts/`。

字体样张验收选择为 A：精绘穆夏原型的英文主标题使用 Great Vibes，中文正文使用 LXGW WenKai。两款字体通过 Windows 私有字体 API 仅注册到原型进程，不安装到系统。

- 不读取截图。
- 不启动语音识别。
- 不连接心跳。
- 不读写 `message_queue.jsonl`、`danmaku.txt` 或其他生产状态文件。
- 输入和回复只保存在当前进程内，关闭窗口后消失。

## 启动

在 GameBuddy 项目目录运行：

```powershell
.\.venv\Scripts\python.exe .\prototypes\pixel_neon_overlay.py
```

若从受限执行环境启动，Tk 可能无法读取用户缓存目录；在普通 Windows 终端运行不受影响。

## 当前可体验内容

- 像素霓虹风格的左右切角消息气泡。
- 青色、品红和暗金色游戏 HUD 状态提示。
- GameBuddy 在线状态与游戏上下文提示。
- 三张截图读取状态的视觉表达。
- 本地假消息发送与假回复。
- MIC 未接线提示。
- 完整窗口与悬浮球之间切换。

## 验收后再做

视觉方向确认后，再逐项把生产能力接入：只读消息渲染、真实发送、语音状态、截图/心跳状态。接入时保留现有队列与桥接协议，不在原型阶段改动生产窗口。
